# AGF 2026 정보

AGF 2026 관련 정보를 확인하기 위한 **비공식 팬메이드 웹사이트**입니다.

> 본 사이트는 AGF 2026 조직위원회 및 AGF Korea와 공식적인 제휴·운영 관계가 없습니다.

## 제공 기능

- 멜론티켓 공식 예매 페이지 연결
- 공식 발표 차수별 참가사 목록과 원문 링크
- RED STAGE 공개 일정과 공식 발표 링크
- BLUE STAGE 공식 일정 공개 여부 안내

## 정보 확인

참가사와 스테이지 정보는 AGF Korea의 공식 채널에서 확인할 수 있도록 원문 링크를 함께 제공합니다. 아직 공개되지 않은 일정이나 부스 번호는 임의로 만들지 않습니다.

- [AGF Korea 공식 X](https://x.com/AGF_Korea)
- [멜론티켓 AGF 예매 페이지](https://ticket.melon.com/csoon/detail.htm?csoonId=12858)

## 기술 구성

- Python
- Flet 1.0.0
- FastAPI
- Uvicorn

## 권리 및 비공식 프로젝트 안내

본 프로젝트는 AGF 공식 웹사이트, 공식 애플리케이션 또는 공식 서비스가 아닙니다. AGF 명칭 및 제3자 자료의 권리는 각 권리자에게 있으며, 공식 로고·사진·게스트 이미지·스테이지 이미지·부스 배치도 등은 사용하지 않습니다.

소스 코드와 제3자 소프트웨어의 권리 및 고지는 `NOTICE` 파일을 참고하세요.
